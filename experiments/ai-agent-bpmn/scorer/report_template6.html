AI Agent BPMN Bake-off

Three ways to build the Camunda "AI Agent Chat With Tools" process from a plain-language spec: a Python generator, a bpmn-js-cli fork extended for Camunda 8, and hand-written XML. The CLI ran in two variants, with and without auto layout. Each ran twice, and every run passed lint and the tutorial's test suite.

Takeaways

  1. A dedicated CLI is faster and cheaper. Without auto layout it averaged 138 seconds and 121k tokens, and with it 150 seconds and 123k (its two runs took 110 and 189 s). Hand-written XML took 164 s and 133k, and Python 168 s and 124k.
  2. Its scripts are short and rebuild the diagram on demand. A script is a list of commands, 72 to 93 lines across the four runs, and re-running it regenerates the file.
  3. Layout by hand is poor. Placing elements with coordinates scored 5.9 of 15 on layout, against 8.1 for Python and 9.5 for hand-written XML, so the CLI was the least close to the canonical file (85.7 of 100, against 87.0 and 89.0).
  4. Auto layout lifts the score, not yet the picture. With bpmn-auto-layout (--autolayout) the CLI scored 89.7 closeness and 9.9 on layout, the highest of any method. The renders are still untidy: in both runs the user task overlaps the sub-process or an annotation, and one run has 2 lint overlap warnings. The score measures distance to the canonical's positions, not overlaps. The library also stacks the tools in one column and drops annotations, so agents still resized the sub-process and shifted nodes by hand.

Read the gaps as suggestive: two trials per method, and the CLI was tuned over rounds that the others did not get. Building the fork is not in its numbers. The Python and hand-written runs also lose 0.3 points each to a c8ctl v4.0.0 bug fixed in camunda/c8ctl#574, which does not change the ranking.

Notes

  • Where points were lost. All six runs differ from the canonical file in the same ways: template defaults it lacks (followRedirects, documentReturnFormat, reasoning effort), ignoreNullValues on the GET tools, which template v18 does not offer, and FEEL written without parentheses. Shape positions differ by 89 to 370 px.
  • CLI gaps the agents reported. Resizing the sub-process and relative append offsets leave the main row misaligned (cli7, cli8), console.log output from model.js is not shown (cli8, cli10), and replace into an ad-hoc sub-process leaves a stray start event that cli10 removed in afterLayout.
  • Method. Done gate: c8ctl bpmn lint with 0 errors, plus the tutorial's 6-scenario test suite. Closeness (0 to 100) is an F1 over facts from both files, weighted structure 25, configuration 50, annotations 10, layout 15. Tokens are the subagent total reported by the harness.
  • The fork is branch camunda-executable of the private repo HanselIdes/bpmn-js-cli. It adds Zeebe, template, annotation and layout commands, per-command help, a filterable template listing and the runner. The specs, runs and scorer are under experiments/ai-agent-bpmn.
