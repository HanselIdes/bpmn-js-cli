# Method: hand-written XML with the camunda-bpmn skill

Write the BPMN XML directly with the Write and Edit tools, following the camunda-bpmn skill:
read `skills/camunda-bpmn/SKILL.md` and the references it points to, in the repository checkout
at /Users/eric.lundberg/GitHub/skills/.claude/worktrees/camunda-strategy-review-459c75.
You may use c8ctl commands as the skill describes (including `element-template apply` and `bpmn format`).
Do not write generator scripts (no Python, Node, or shell scripts that emit XML) and do not use bpmn-js.
